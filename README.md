# 한국사 연상 노트

한능검 학습을 위한 시대별 암기 노트입니다. 113개 주제와 170개 YouTube 쇼츠를 모았습니다.

사이트: https://zekelee.github.io/history/

## 기능
- 시대별 목차와 부드러운 이동, 스크롤에 따른 메뉴 활성화
- 암기 단서·설명·비교표와 검색
- 항목 안에서 YouTube 쇼츠 재생
- Pretendard 웹폰트, 모바일 대응, 인쇄

## 수정 및 배포
`index.html`은 학습 내용, `assets/styles.css`는 디자인, `assets/app.js`는 동작을 담당합니다.
`main` 브랜치의 루트 폴더를 GitHub Pages로 배포합니다. 변경 사항을 push하면 자동 반영됩니다.

영상은 원본 YouTube 콘텐츠를 임베드하며, 영상과 웹폰트는 인터넷 연결이 필요합니다. 영상에 따라 외부 재생이 제한될 수 있어 YouTube 원본 링크도 제공합니다.

영상 출처: [공부한의사 쏘팟](https://www.youtube.com/@user-studoc/shorts)
글꼴: [Pretendard](https://github.com/orioncactus/pretendard)
